# Tài liệu dự án

Thư mục tập trung tài liệu viết của nhóm. Hướng dẫn chạy nhanh nằm ở [README gốc](../README.md); thiết kế gốc là `BigData.pdf`, yêu cầu môn học là `Projects.pptx.pdf` (ở gốc repo).

| Tài liệu | Nội dung | Ai đọc |
| --- | --- | --- |
| [BAO_CAO_TIEN_DO.md](BAO_CAO_TIEN_DO.md) | Báo cáo tiến độ: đối chiếu F1–F6, số liệu, kết quả chạy, kiểm thử, kịch bản trình bày | Giảng viên, cả nhóm |
| [CHECKPOINT_TIEN_DO.docx](CHECKPOINT_TIEN_DO.docx) | Bản Word tóm tắt tiến độ để nộp/in | Giảng viên |
| [PLAN.md](PLAN.md) | Trạng thái theo giai đoạn, thay đổi gần đây, việc còn lại, phân công | Cả nhóm |
| [decisions.md](decisions.md) | Các quyết định đã chốt và lý do; câu hỏi chờ giảng viên | Cả nhóm, thành viên mới |
| [van_de_va_giai_phap_ha_tang.md](van_de_va_giai_phap_ha_tang.md) | Vấn đề tài nguyên, đề xuất ban đầu và cách đã áp dụng | Cả nhóm |
| [architecture.md](architecture.md) | Luồng dữ liệu, thứ tự job, schema, luật phát hiện bất thường, chịu lỗi | Người viết code |
| [collection_guide.md](collection_guide.md) | Thu thập từ Steam: endpoint, chọn game, chống trùng, lịch thu | Người crawl |
| [local_setup_guide.md](local_setup_guide.md) | Cài môi trường local, HDFS, Kafka trên Linux/WSL2 | Người chạy local |
| [deployment_guide.md](deployment_guide.md) | Triển khai trên Kubernetes | Người phụ trách cụm |
| [reports/](reports/) | Báo cáo kiểm tra theo từng lần (ví dụ crawl thử 30 game) | Tham khảo |

Tài liệu liên quan ngoài thư mục này: [infra/demo/README.md](../infra/demo/README.md) (Docker Compose một máy), [infra/k3s/README.md](../infra/k3s/README.md) và [infra/k3s/FAULT_TEST.md](../infra/k3s/FAULT_TEST.md) (cụm k3s, kiểm thử chịu lỗi), [dashboards/README.md](../dashboards/README.md).

Khi cập nhật: ghi ngày ở đầu file; số liệu phải đếm lại từ dữ liệu, không chép từ bản cũ.
